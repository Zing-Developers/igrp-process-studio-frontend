# Usage

## Requirements

- install packages  ```pnpm add jsonwebtoken lru-cache @irn/irn-backoffice-integration @irn/irn-backoffice-design-system```
- required variables
  - ```IRN_API_BACKOFFICE_BASE_URL```
  - ```JWT_KEY```
  - ```JWT_PRIVATE_KEY```
  - ```NEXT_PUBLIC_ALLOWED_DOMAINS```
  - ```AUTH_LOGIN_PATH_URL```

## use the irn-layout as wrapper

- use irn-layout and wrap the whole app
