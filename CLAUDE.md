# Claude Code Guide

Before starting, resuming, or reviewing feature work, read
[specs/INDEX.md](specs/INDEX.md).

For the selected feature, read its specification, plan, tasks, and verification
artifacts in that order. The dashboard is a summary only; feature artifacts are
the source of truth.

Update tasks and verification evidence before updating the dashboard whenever a
feature's lifecycle status, blocker, or next action changes.

Do not edit generated source under `src/app/(igrp)/(generated)`. Change the
source configuration or generator contract instead.
